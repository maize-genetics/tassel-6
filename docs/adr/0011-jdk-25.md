# ADR-0011: JDK 25 for JVM targets

- Status: Accepted
- Date: 2026-10-29

## Context

JVM builds (desktop app, CLI, server, bridge) benefit from fast native math.
The Foreign Function & Memory (FFM) API, final since JDK 22, can call OpenBLAS
and LAPACK without JNI. JDK 25 is the current LTS release.

## Decision

All JVM modules use a JDK 25 toolchain. JVM-only fast paths (OpenBLAS through
FFM, optionally the Vector API) live in `jvmMain` behind the same interfaces as
the pure-Kotlin implementations.

## Consequences

- Users of the JVM builds need JDK 25; the desktop app bundles its own runtime.
- The legacy bridge runs TASSEL 5 on JDK 25 and must be tested for any
  incompatibilities.
- The pure-Kotlin path stays the reference implementation for parity tests.

## Alternatives considered

- JDK 21 LTS: no final FFM until 22; would need JNI or a preview flag.
- JDK 17: matches older environments but lacks FFM and modern GC improvements.
